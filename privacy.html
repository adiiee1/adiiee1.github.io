Privacy Policy - Adarsh Ride Uploader

Last updated: 16 November 2026

1. Who uses this app

Adarsh Ride Uploader is a private tool used only by the owner of the YouTube channel "Adarsh Patanayak". It is not available to anyone else.

2. What data it accesses

With the owner's permission (Google OAuth), the app uses the YouTube Data API and YouTube Analytics API to access only the owner's own channel: his videos, their titles, descriptions, tags, thumbnails, playlists, schedules, and channel analytics.

3. How the data is used

The data is used only to upload and manage the owner's own videos and to view his own channel performance. It is not sold, shared, or used for advertising.

4. Storage

The sign-in token is stored only on the owner's personal computer. No data is stored on any server. The app does not collect data about viewers or other YouTube users.

5. Google and YouTube

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's Privacy Policy applies.

6. Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
